⚡ Design Patterns

System Architecture

Five design patterns working in harmony, extracted from Main.java

🔒
Singleton Creational

LoanCoordinator and LoanManagementSystem use the Singleton pattern — guaranteeing a single instance to coordinate all loan processing and observer notifications.

class LoanCoordinator { private static LoanCoordinator instance; public static LoanCoordinator getInstance() { if (instance == null) instance = new LoanCoordinator(); return instance; } }
👁️
Observer Behavioral

AuditDepartment and AccountsDepartment observe loan approvals. When a loan is approved, both departments are automatically notified for logging and risk checks.

interface LoanObserver { void update(Loan request, String approver); } class AuditDepartment implements LoanObserver { // Loan logged for ₹amount approved by approver } class AccountsDepartment implements LoanObserver { // Disbursement and risk allocation checked }
🏭
Abstract Factory Creational

SalariedLoanFactory and SelfEmployedLoanFactory create the correct loan type (Personal, Housing, Vehicle) based on the applicant's employment status.

abstract class LoanFactory { abstract Loan createLoan(type, amount, notifier); } class SalariedLoanFactory extends LoanFactory { // → SalariedPersonalLoan // → SalariedHousingLoan // → SalariedVehicleLoan }
🌉
Bridge Structural

NotificationChannel decouples the notification mechanism (Email, SMS, Mobile App) from the loan processing logic, allowing independent variation.

interface NotificationChannel { void sendNotification(String message); } class EmailNotification implements NotificationChannel class SMSNotification implements NotificationChannel class MobileAppNotification implements NotificationChannel
⛓️
Chain of Responsibility Behavioral

Loan requests flow through BranchManager → RegionalHead → RiskCommittee. Each handler approves within its limit or forwards to the next level.

BranchManager: ≤ ₹50,000 → Approved RegionalHead: ≤ ₹2,00,000 → Approved RiskCommittee: ≤ ₹5,00,000 → Approved // Amount > ₹5,00,000 → REJECTED
🛡️
Proxy Structural

ProxyLoanManagementService authenticates employees before granting access to the real LoanManagementSystem. Invalid credentials are blocked at the gate.

class ProxyLoanManagementService { private boolean authenticate() { String[] knownIds = {"EMP101","EMP102","EMP103"}; String[] knownPass = {"pass101","pass102","pass103"}; // match username & password } }
